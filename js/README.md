# Visualization Scripts

This folder contains all D3.js (v7) modules that power the interactive data storytelling page at `docs/index.html`.

## File Overview

| File | Chart | Data source |
|:-----|:------|:------------|
| `vizB.js` | Scatter plot — predicted vs observed consumption | `data/rf_scatter.json` |
| `vizC.js` | Choropleth map — mean MAPE by region | `data/region_metrics.json` + GeoJSON (remote) |
| `vizD.js` | Quantile dot plot — error distributions by region | `data/violin_data.json` |
| `vizE.js` | Scatter — population density vs mean MAPE | `data/viz_e_data.json` |
| `vizANOVA.js` | ANOVA summary + ranked bar chart | `data/anova_results.json` |
| `d3.v7.min.js` | D3.js v7 (bundled locally) | — |

## How to Run the Project

> **You cannot open `docs/index.html` directly by double-clicking.** Browsers block local JSON file requests (CORS policy), so the charts will not load. You need a local HTTP server.

### Option 1 — Python (no installation needed)

From the project root:

```bash
python -m http.server 8000
```

Then open: [http://localhost:8000/docs/index.html](http://localhost:8000/docs/index.html)

### Option 2 — Node.js

```bash
npx serve .
```

Then open the URL shown in the terminal (usually `http://localhost:3000/docs/index.html`).

### Option 3 — VS Code Live Server

1. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension
2. Right-click `docs/index.html` in the file explorer
3. Select **"Open with Live Server"**

## Regenerating the Data Files

The JSON files in `data/` are generated by `notebooks/03_visualizations.ipynb`.  
If you retrain the model or update the test set, re-run that notebook from top to bottom to refresh all chart data before serving the page.
